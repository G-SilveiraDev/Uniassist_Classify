# UniAssist — Classificador de Mensagens

Projeto acadêmico em Python que compara dois métodos de classificação de solicitações estudantis: regras baseadas em palavras-chave e Machine Learning com TF-IDF e LinearSVC.

O objetivo é identificar o setor responsável por cada mensagem: **Financeiro, Matrícula, Estágio ou Suporte**. O projeto apresenta métricas de desempenho, matrizes de confusão e análise de mensagens ambíguas, discutindo as limitações dos métodos e a necessidade de revisão humana.

**Tecnologias utilizadas:** Python e scikit-learn.
